Sao lưu / khôi phục

Sao lưu định kỳ để tránh mất dữ liệu khi đổi hoặc hỏng thiết bị.

Đồng bộ máy tính và điện thoại qua Supabase

Đồng bộ đám mây cần tạo dự án Supabase miễn phí và nhập thông tin kết nối một lần. Chưa có khóa kết nối nên tính năng này chưa thể tự hoạt động ngay.

Chưa cấu hình đồng bộ.

Hướng dẫn tạo bảng đồng bộ

Trong Supabase → SQL Editor, chạy đoạn SQL sau. Sau đó bật Row Level Security và tạo chính sách riêng tư phù hợp trước khi dùng dữ liệu thực tế.

create table if not exists public.inventory_state (
  id text primary key,
  owner_id uuid not null references auth.users(id) default auth.uid(),
  payload jsonb not null,
  updated_at timestamptz default now()
);
alter table public.inventory_state enable row level security;
create policy "owner reads own state" on public.inventory_state
for select to authenticated using (auth.uid() = owner_id);
create policy "owner inserts own state" on public.inventory_state
for insert to authenticated with check (auth.uid() = owner_id);
create policy "owner updates own state" on public.inventory_state
for update to authenticated using (auth.uid() = owner_id)
with check (auth.uid() = owner_id);

Sau khi tạo bảng, tạo tài khoản email trong Supabase Authentication → Users (hoặc đăng ký trong Authentication), rồi đăng nhập bằng email/mật khẩu trong phần mềm. RLS chỉ cho người dùng đã đăng nhập đọc/ghi. Public key có thể nằm trong trình duyệt; tuyệt đối không đặt service_role key vào phần mềm.
